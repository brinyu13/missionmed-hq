# Profile Personalization

The no-profile path is fail-soft: canonical program evidence remains visible and the UI states that Matrix is unavailable rather than inventing personalized conclusions. Live Founder QA showed `Profile 0% complete` and normal browsing.

Private preferences support:

- application priorities;
- visible card fields;
- criteria/profile/CV presentation modes;
- subject-isolated storage protected by RLS.

Saving card preferences and the existing My Programs state passed browser tests. A normal student cannot read another subject's private data or reach admin controls under the tested authorization contract.
