# I1Q-1006 Phase 0 Adversarial Audit

This directory is an independent, Node.js built-in-only audit harness for the synthetic I1Q-1005 foundation estate. It performs no production reads, network calls, package installs, migrations, runtime changes, or publication. Production remains blocked.

## Scope And Isolation

- Persistent writes are limited to this `audit/**` directory.
- The 1005 validator and fixtures are read-only inputs.
- `run_official_1005_isolated.mjs` copies the 1005 estate to an OS temporary directory, verifies that the copied validator has the same SHA-256 as the source, executes those unchanged bytes, deletes the temporary tree, and proves the source estate hash did not change.
- The source privacy corpus is evaluated as-is and is expected to fail the superseding aggregate because `FAKE-PAT-0001` is labeled `student_name`, leaving `patient_identifier` absent. The mutation catalog then uses an in-memory synthetic control that corrects this label and declares all required classes. The source fixture is never edited.
- All fixtures use the existing synthetic Orbital Gardening Certification domain. No medical, student, secret, credential, or production data is used.

## Commands

Run the complete audit:

```sh
node _AI_HANDOFFS/from_codex/I1Q_STATQUESTIONS_1006_ULTRA_BUILD/audit/run_all.mjs
```

Run components independently:

```sh
node _AI_HANDOFFS/from_codex/I1Q_STATQUESTIONS_1006_ULTRA_BUILD/audit/run_official_1005_isolated.mjs
node _AI_HANDOFFS/from_codex/I1Q_STATQUESTIONS_1006_ULTRA_BUILD/audit/run_adversarial_audit.mjs
```

Each command exits nonzero on any failed assertion.

## Superseding Privacy Aggregate

`evaluatePrivacyAggregate` replaces the ambiguous aggregate behavior exercised by the 1005 scorer for this audit:

- Every required class is always present in `by_class`: `address_like`, `email`, `patient_identifier`, `student_name`, and `third_party_name`.
- A required class with zero gold examples is marked missing, receives recall `0`, and fails.
- `patient_identifier` recall is always a finite number, including zero-denominator cases.
- Every class records precision and recall denominator-zero flags and named resolution behavior.
- Zero predictions with positive gold produce precision `0`; zero predictions with zero gold produce precision `1`; required-class zero gold produces recall `0` and fails.
- Aggregate zero predictions produce precision `1`; aggregate zero gold produces recall `0`.
