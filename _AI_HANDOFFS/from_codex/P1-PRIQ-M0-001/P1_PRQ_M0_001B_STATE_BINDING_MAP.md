|---|---|---|---|
| `FOUNDATION_READY` | Always for the installed local foundation | Today | Confirms the bounded foundation, not production readiness |

Additional bindings: provider health, source coverage, current cost, last latency, run count, monthly budget, provider route, cue minimum gap, all feature flags, fixture identity, migration status, production-connection status, and audit events.
