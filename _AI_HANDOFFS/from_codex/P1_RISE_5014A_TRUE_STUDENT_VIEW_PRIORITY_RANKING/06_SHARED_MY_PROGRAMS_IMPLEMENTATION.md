# Shared My Programs Implementation

Student and delegated-administrator views use the same canonical My Programs service and rows.

The administrator surface can:

- search/select an authorized student;
- inspect the student's canonical list and current student-owned state;
- move a program up or down in priority;
- open a program file in delegated read-only context.

The administrator surface cannot save/unsave, star/unstar, change application status, edit notes, or impersonate the student. These restrictions exist in both the interface and server authorization.
