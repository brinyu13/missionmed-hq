# B1-508 Student-Ready Acceptance

## Product result

The core text product is operationally ready for an explicitly authorized
identity or cohort:

- authenticated Matrix entry works;
- Home and navigation are recognizable;
- Quick Capture creates a private durable story;
- autosave and explicit save are truthful;
- reload retains work;
- story detail preserves immutable original capture;
- Library and Interview Prep work;
- disabled voice does not block text use;
- role and access are server-derived;
- private direct-ID isolation and mentor/admin boundaries pass.

## Current authority result

Only the Founder identity is enabled. No designated test student or student
cohort was authorized in B1-508, so no student identity was added and no claim
of an initial student release is made.

## Exact expansion gate

Provide an explicit list of approved WordPress user IDs or a bounded cohort
rule, plus the intended role. Then:

1. back up current StoryForge WordPress settings;
2. add only those identities/cohort;
3. wait one JWT TTL;
4. verify one eligible and one ineligible account;
5. run the same text create/save/reload/isolation canary;
6. retain voice force-off and provider none.

This is a policy/identity action, not missing application engineering.
