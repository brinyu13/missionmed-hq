# Agent Report — Evidence Curators

## Assignment

Two independent specialist passes proposed diverse, unambiguous single-best-answer drafts using current official or primary sources, four homogeneous choices, correct/distractor rationales, Level 3 teaching material, and balanced answer positions. No physician approval was to be implied.

## Output

- 24 specifications across emergency medicine, cardiology, toxicology, neurology, obstetrics, pediatrics, infectious disease, gastroenterology, hematology, endocrinology, nephrology, psychiatry, surgery, rheumatology, dermatology, oncology, and preventive medicine.
- Each 12-item set independently balanced A/B/C/D = 3/3/3/3; the combined bank is 6/6/6/6.
- Sources included CDC, NIH institutes, ACOG, AHA, WHO, AASLD, ISTH, NICE, USPSTF, and specialty society guidance.
- One precision amendment changed the preeclampsia stem from vague “elevated” blood pressure to explicit repeat measurements.

## Curation rules applied

- Avoid dosing questions and intentionally controversial comparisons.
- Prefer stable emergency priorities, syndrome definitions, diagnostic localization, and timing principles.
- Mark volatile topics for earlier review.
- Use one best answer and distractors reflecting named misconceptions.
- Keep every item quarantined, citation-unverified, physician-review-required, and release blocked.

## Limitations

The curators performed AI-assisted source review, not credentialed medical approval. Official URLs and locators are proposed evidence; they still require immutable retrieval, claim-entailment adjudication, conflict checks, and exact-hash physician review.
