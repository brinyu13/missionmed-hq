# Root causes

- Equal-width CSS grids and restrictive width rules created dead space and card towers.
- The live canonical projection did not consistently map `roleCategory` leadership evidence into the program model; cached/generated serving state preserved the gap.
- A presentation token intended for accents was applied to leadership role/body text.
- Filter ordering relied on presentation order rather than applicant-first DOM order.
- The generic people renderer preserved upstream ordering and lacked deterministic hierarchy/name deduplication.
- Resident absence, unknown composition and researched-not-public states were not kept sufficiently distinct in every surface.
