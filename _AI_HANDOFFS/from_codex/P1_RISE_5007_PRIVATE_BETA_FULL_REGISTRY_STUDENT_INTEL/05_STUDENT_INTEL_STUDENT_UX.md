# Student Intel Student UX

The Program File Overview receives an additive `Student Intel` section below the locked overview content. It is clearly labeled `Community evidence` and states that reports are leads, not canonical facts.

Eligible students can submit:

- the Program/RISE identifier inherited from the Program File;
- one of the 18 required categories;
- a free-text claim;
- source kind, HTTPS URL when online, and source label;
- observed/source date;
- private context;
- `SHOW MY NAME` or `ANONYMOUS TO STUDENTS`.

Cards show category, claim, date, clickable source, verification state, safe public contributor identity, public MissionMed notation, corroboration count, and high-priority waiting state. Hidden, rejected, and deleted records disappear from every student projection, including the original contributor's view.

The student API never returns submitter subject, hidden name, private context, original-vs-edited history, or admin audit metadata.
