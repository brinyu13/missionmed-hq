# 10 — Research Command Center

The Fable admin interaction model is preserved locally: Research, Queue, Review, Coverage; scoped builder; natural-language draft; preview-before-spend; status/review empty states.

Because no authorized research backend exists:

- ordinary students cannot see admin controls;
- the UI states that the factory is not authorized;
- program/task/processor/cost values are not fabricated;
- Run Research is disabled;
- natural language creates only a local draft explanation;
- queue/review are honest unconnected empty states;
- no accept/overwrite/research-again mutation is possible.

The paid-submission law is enforced by absence: no unbounded natural-language request can trigger spend, and no Parallel key exists client-side.
