# Sanitized evidence receipts

This directory contains aggregate, zero-retention evidence only. Runtime identifiers,
titles, source locations, transcript text, speaker strings, credentials, and request
headers are intentionally excluded. Per-run aliases are keyed and cannot be correlated
across executions.

Artifact hashes establish byte identity only. They do not establish corpus membership,
speaker authority, rights, privacy clearance, medical accuracy, or semantic equivalence.
