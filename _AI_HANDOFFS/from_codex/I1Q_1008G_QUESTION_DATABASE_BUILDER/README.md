# I1Q-1008G Dr. J Question Database Builder

This package transforms the accepted I1Q-1008F Gold Set into an occurrence-preserving Question Database. It does not extract, deduplicate, canonicalize, rewrite, merge, generate MCQs, build an ontology, release learner content, or mutate production.

Restricted outputs live under the `TARGET_BOUNDARY` alias. Git contains only schemas, deterministic builders and validators, aggregate evidence, and leakage-safe reports.

Start with [COMPLETE_COMBINED_HANDOFF.md](COMPLETE_COMBINED_HANDOFF.md), then inspect [QUESTIONS_PER_DRILL.md](reports/QUESTIONS_PER_DRILL.md) and [validation-safe-summary.json](evidence/validation-safe-summary.json).
